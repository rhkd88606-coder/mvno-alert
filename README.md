# 알뜰폰 요금제 알림

디시인사이드 알뜰폰 마이너 갤러리를 10분마다 확인해서, 좋은 요금제 글이 올라오면 디스코드로 알려줘요.

알려주는 글:
- 말머리가 행사인 글은 무조건
- 말머리나 제목에 굴비, 전설, 대란이 들어간 글
- 제목에 평생 + 통화·문자 무제한 + 770원 이하가 보이는 글
- 제목에 이심 또는 5G + 30GB 이상 + 100원 이하가 보이는 글

설정: 저장소 Settings → Secrets and variables → Actions 에 `DISCORD_WEBHOOK_URL` 이름으로 디스코드 웹훅 주소를 넣어요.
